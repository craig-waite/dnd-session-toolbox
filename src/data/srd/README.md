# SRD data

Source: [5e-bits/5e-database](https://github.com/5e-bits/5e-database) (`src/2014/en`), which structures the D&D 5th Edition System Reference Document (SRD 5.1) into JSON.

The SRD is released by Wizards of the Coast under the [Open Game License 1.0a](https://media.wizards.com/2016/downloads/DND/SRD-OGL_V5.1.pdf). Content here is limited to SRD material — no non-SRD book content (e.g. Monster Manual entries not also in the SRD) is included, since that remains copyrighted by Wizards of the Coast.

Re-run the download to refresh this data:

```
curl -s -o <name>.json "https://raw.githubusercontent.com/5e-bits/5e-database/main/src/2014/en/<name>.json"
```
